# 🌈 Grow With Me

An interactive pregnancy journey app designed to help expecting mothers visually connect with their baby, track meaningful moments, and build emotional bonding through a beautiful, engaging experience.

---

## ✨ Overview

**Grow With Me** is a web-first application that transforms pregnancy tracking into a visual, interactive journey.

Instead of static data and generic dashboards, the app focuses on:

- Emotional connection
- Visual storytelling
- Daily engagement

This project is designed to launch as a **web app (MVP)** and later evolve into a **mobile app**.

---

## 🎯 Core Features

### 🍼 1. Interactive Baby Timeline (Grow With Me)

- Week-by-week visual baby development
- Swipe or scroll-based navigation through pregnancy weeks
- Tap interaction to reveal:
  - Baby size
  - Development highlights
- Smooth animations to simulate growth progression

**Goal:** Make pregnancy feel real and tangible through visuals.

---

### 💬 2. Talk to Baby (Bonding Feature)

- Record voice messages per week
- Save short notes or letters
- Optional playback with soft effects (e.g., muffled “womb-like” audio)
- Timeline-based memory organization

**Goal:** Encourage emotional bonding between mother and baby.

---

### 🎮 3. Kick Play (Interactive Kick Tracker)

- Simple tap-based kick logging
- Visual feedback (e.g., ripple, sparkle animations)
- Daily summaries of activity
- Trend visualization (activity patterns over time)

**Goal:** Turn a medical task into a delightful daily interaction.

---

### 🧘 4. Mood Garden (Emotional Tracker)

- Daily mood input (simple, non-intrusive)
- Visual garden that evolves:
  - Positive mood → growth/bloom
  - Stress → subtle changes in environment
- Timeline view of emotional journey

**Goal:** Provide a soft, visual outlet for emotional tracking.

## 🏗️ Tech Stack (Proposed)

### Frontend (Web MVP)

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animation:**
  - Rive or Lottie
  - Framer Motion

### Backend

- **API:** Next.js API routes or separate Node.js service
- **Database:** PostgreSQL (or Supabase)
- **Auth:** NextAuth / Auth.js

### Storage

- Voice recordings: Cloud storage (S3 / Supabase Storage)
